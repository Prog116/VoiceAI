# VoiceAI(Whisper Flow)

Голосовой ввод для Windows с графическим интерфейсом: зажали клавишу — говорите, отпустили — распознанный и очищенный от слов-паразитов текст автоматически вставляется в активное окно.



Возможности:



Push-to-talk: запись идёт, пока зажата клавиша F9 (работает даже когда окно приложения свёрнуто или не в фокусе)

Распознавание речи через Groq Whisper API (whisper-large-v3-turbo), аудио передаётся в сжатом FLAC

Локальная очистка текста от слов-паразитов (без дополнительного сетевого запроса)

Автоматическая вставка результата в буфер обмена и активное окно

Графический интерфейс на egui:

вкладка Главная — статус (ожидание/запись/обработка) и история распознанных фраз

вкладка API Ключ — ввод и хранение ключа Groq прямо в приложении

вкладка Слова-паразиты — редактирование списка без правки .env

опциональный плавающий мини-виджет поверх всех окон с индикатором статуса

Выход из приложения — клавиша F12



⚠️ Режим работы: облачный



Приложение отправляет записанное аудио на серверы Groq (США) для распознавания речи через Whisper API. Аудио передаётся по HTTPS в сжатом виде (FLAC) и не сохраняется локально после обработки, но покидает устройство пользователя — учитывайте это при использовании для чувствительных данных.



Для работы обязательно требуется интернет-соединение. Локальный (офлайн) режим распознавания не реализован.



Требования:



Windows 10/11

Rust toolchain: rustc 1.98.1

Микрофон

API-ключ Groq — получить на console.groq.com

Установка и запуск

Клонировать репозиторий:

powershell

&#x20;  git clone https://github.com/Prog116/VoiceAI.git

&#x20;  cd VoiceAI

(Необязательно) Создать файл .env в корне проекта, чтобы не вводить ключ вручную при каждом запуске:

&#x20;  GROQ\_API\_KEY=ваш\_ключ\_здесь

&#x20;  FILLER\_WORDS=эм,ну,как бы,типа,короче



Если .env не создан — ключ и список слов-паразитов можно ввести прямо в интерфейсе приложения, во вкладках API Ключ и Слова-паразиты.



Собрать и запустить:

powershell

&#x20;  cargo run --release

Использование:



При первом запуске (если не заполнен .env) откройте вкладку API Ключ и вставьте ключ Groq

Зажмите F9 и говорите — статус на главном экране сменится на «🔴 Запись...»

Отпустите F9 — начнётся обработка («⚙ Обработка...»), после чего текст автоматически вставится в то окно, где стоит курсор, и появится в истории

При желании включите плавающий мини-виджет (чекбокс на главной вкладке) — компактный индикатор статуса поверх всех окон, удобно при работе в других приложениях

F12 — закрыть приложение (работает из любого окна, фокус не важен)

Конфигурация



Значения по умолчанию можно задать через .env, а затем изменить прямо в интерфейсе (изменения в GUI действуют до перезапуска приложения, .env при этом не перезаписывается):



Переменная	Обязательна	Описание

GROQ\_API\_KEY	нет\*	Ключ доступа к Groq API

FILLER\_WORDS	нет	Список слов-паразитов через запятую для локальной очистки (по умолчанию: эм,ну,как бы,типа,короче)



\* Без ключа (ни в .env, ни введённого в GUI) распознавание работать не будет.



Сборка релизной версии

powershell

cargo build --release



Исполняемый файл появится в target/release/whisper\_flow\_rust.exe. Собирается без консольного окна (#!\[windows\_subsystem = "windows"]) — запускается как обычное GUI-приложение.

Технические детали

Аудио записывается через cpal, ресемплируется до 16 кГц моно

Перед отправкой кодируется в FLAC (без потерь) — заметно быстрее, чем передача сырого WAV

Очистка от слов-паразитов выполняется локально, без дополнительного запроса к LLM

Интерфейс построен на egui/eframe, фоновая обработка (запись, сеть) идёт в отдельных потоках, не блокируя UI



\## Fail-safe



\- \*\*Отказ распознавателя.\*\* Если запрос к Groq API завершается ошибкой (сеть, неверный ключ, недоступность сервиса) — приложение не падает: ошибка перехватывается, записывается в историю с пометкой `❌ Ошибка`, и работа продолжается со следующей репликой.

\- \*\*Пустая реплика не вызывает вставку.\*\* Если Whisper вернул пустой текст (тишина, нераспознанная речь) — вставка в активное окно не происходит, буфер обмена не трогается.

\- \*\*Отсутствие API-ключа не приводит к падению.\*\* Если ключ не задан ни в `.env`, ни в интерфейсе, приложение запускается нормально — ошибка отобразится только при попытке распознавания, а не при старте.

\- \*\*Буфер обмена восстанавливается.\*\* После вставки распознанного текста приложение возвращает в буфер обмена то значение, которое было там до вставки, — предыдущий буфер пользователя не теряется.



Известные ограничения:



Требует интернет-соединение (облачное распознавание)

Не тестировалось на Linux/macOS (использует Windows-специфичную симуляцию нажатий клавиш через rdev и скрытие консоли через windows\_subsystem)

Ключ и список слов-паразитов, изменённые в GUI, не сохраняются обратно в .env — при перезапуске приложение снова подхватит значения из .env (или пустую строку, если файла нет)
