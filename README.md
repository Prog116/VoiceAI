# VoiceAI (Whisper Flow)

Голосовой ввод для Windows с графическим интерфейсом: говорите — распознанный и очищенный текст автоматически вставляется в активное окно. Поддерживаются два режима записи: «Рация» (зажали клавишу — говорите, отпустили — вставка) и «Переключатель» (нажали — запись, нажали ещё раз — вставка).

**Распознавание речи выполняется полностью локально** — движок `whisper.cpp` через крейт `whisper-rs`. Облачных API и отправки аудио на серверы нет.

## Возможности

- Два режима записи:
  - **Рация** — запись идёт, пока зажата клавиша (по умолчанию `F9`)
  - **Переключатель** — нажатие начинает запись, повторное нажатие останавливает
- **Локальное распознавание** через `whisper-rs` (модель `ggml-large-v3-turbo`), язык распознавания — русский
- Выбор **входного устройства** (микрофона) в настройках со списком доступных устройств и кнопкой обновления
- Автоматическое скачивание модели с Hugging Face при первом запуске, если её нет рядом с приложением (в фоне, с прогресс-баром во вкладке «Настройки»)
- Локальная очистка текста от слов-паразитов (без сетевых запросов)
- Замена слов и фраз при распознавании (например, «дефис» → «-»)
- Настройки (горячие клавиши, стоп-слова, замены слов, усиление микрофона, режим записи, устройство ввода) сохраняются в `.env` и переживают перезапуск
- Настройка усиления микрофона и предобработка аудио: приведение к моно, ресемплинг до 16 кГц, адаптивный шумовой порог, нормализация
- Автоматическая вставка результата в активное окно; прежнее содержимое буфера обмена восстанавливается
- **Иконка в системном трее**: синяя в покое, красная во время записи. Левый клик (или пункт меню «Открыть VoiceAI») возвращает главное окно, меню также содержит «Выход»
- **Сворачивание в трей**: закрытие главного окна прячет его, приложение продолжает работать; вернуть окно можно кликом по иконке в трее
- **Один экземпляр приложения**: повторный запуск не создаёт вторую копию, а показывает уже запущенное окно
- Графический интерфейс на `egui`:
  - вкладка **Главная** — статус (ожидание/запись/обработка) и история
  - вкладка **Настройки** — тема, устройство ввода, усиление микрофона, режим записи, горячие клавиши, путь к модели, стоп-слова и замены слов
  - опциональный плавающий мини-виджет поверх всех окон с индикатором статуса (перетаскивается мышью)
- Выход из приложения — клавиша (по умолчанию `F12`) или пункт «Выход» в меню трея

## История

- Хранится в `history.jsonl` в рабочей папке, ограничение — 2000 последних записей
- Записи **сгруппированы по дате**: «Сегодня», «Вчера», «На прошлой неделе», для более старых — конкретная дата; в заголовке группы показано количество записей
- Группы можно **сворачивать/разворачивать** кликом по заголовку
- У каждой записи показано время
- Поиск по тексту, копирование в буфер по кнопке или клику, удаление отдельных записей, полная очистка
- Экспорт всей истории в отдельный файл `export_<timestamp>.jsonl`

## Режим работы: локальный (офлайн)

**Приложение работает автономно, без облачных сервисов.** Аудио не покидает устройство: запись, обработка и распознавание выполняются локально через `whisper.cpp`.

Сеть нужна только один раз — при первом запуске, когда модель (`ggml-large-v3-turbo.bin`, ~1.6 ГБ) скачивается с Hugging Face, если её ещё нет в папке `models/`. После загрузки модели интернет не требуется.

## Требования

- Windows 10/11
- Стабильный Rust (edition 2021) и инструменты сборки MSVC
- **NVIDIA GPU** — распознавание использует CUDA. Для сборки из исходников нужен также CUDA Toolkit; в готовом релизе нужные библиотеки уже упакованы, устанавливать CUDA не требуется
- Микрофон
- Интернет и свободное место на диске (~1.6 ГБ) для однократной загрузки модели

> Если CUDA-сборка не нужна, функцию `cuda` можно убрать из `whisper-rs` в `Cargo.toml` — тогда распознавание пойдёт на CPU (медленнее, без требований к GPU).

## Установка и запуск

1. Клонировать репозиторий:
```powershell
   git clone https://github.com/Prog116/VoiceAI.git
   cd VoiceAI
```

2. *(Необязательно)* Создать файл `.env` в корне проекта для заданий значений по умолчанию (см. «Конфигурация»). Без `.env` приложение использует встроенные значения, а все настройки можно менять прямо в интерфейсе — изменённые настройки сохраняются в `.env` автоматически.

3. Собрать и запустить:
```powershell
   cargo run --release
```

При первом запуске, если файла модели нет, она скачивается автоматически в фоне — интерфейс открывается сразу, а прогресс загрузки виден во вкладке «Настройки» (блок «🤖 Модель Whisper»).

## Использование

1. Дождитесь загрузки модели (при первом запуске) — статус на главной вкладке сменится на «🟢 Ожидание»
2. Выберите режим записи в настройках: **Рация** или **Переключатель**
3. Запишите фразу:
   - в режиме **Рация** — зажмите клавишу записи (по умолчанию **F9**), говорите и отпустите
   - в режиме **Переключатель** — нажмите клавишу записи для начала и ещё раз для остановки
4. После остановки начнётся «⚙ Обработка...», затем текст автоматически вставится в активное окно и появится в истории
5. При желании включите **плавающий мини-виджет** (чекбокс на главной вкладке) — компактный перетаскиваемый индикатор статуса поверх всех окон
6. Закрытие главного окна сворачивает приложение в **трей** (иконка синяя/красная). Вернуть окно — клик по иконке. Полный выход — **F12** или «Выход» в меню трея

## Конфигурация

Значения по умолчанию задаются через `.env`. Большинство настроек меняется прямо в интерфейсе и автоматически сохраняется в `.env`: горячие клавиши — при назначении, стоп-слова, замены слов, усиление микрофона, режим записи и устройство ввода — по мере изменения.

| Переменная            | Обязательна | По умолчанию                      | Описание                                                        |
|-----------------------|:-----------:|-----------------------------------|-----------------------------------------------------------------|
| `WHISPER_MODEL_PATH`  | нет         | `models/ggml-large-v3-turbo.bin`  | Путь к файлу модели `.bin`                                      |
| `HOTKEY_RECORD`       | нет         | `F9`                              | Клавиша записи, перезаписывается из интерфейса                  |
| `HOTKEY_EXIT`         | нет         | `F12`                             | Клавиша выхода, перезаписывается из интерфейса                  |
| `RECORDING_MODE`      | нет         | `hold`                            | Режим записи: `hold` (Рация) или `toggle` (Переключатель)       |
| `INPUT_DEVICE`        | нет         | *(системный по умолчанию)*        | Имя входного устройства (микрофона); пусто — устройство по умолчанию |
| `MIC_GAIN`            | нет         | `10`                              | Усиление сигнала микрофона (1–50)                               |
| `FILLER_WORDS`        | нет         | `эм,ну,как бы,типа,короче`        | Список слов-паразитов через запятую для локальной очистки       |
| `WORD_REPLACEMENTS`   | нет         | см. ниже                          | Замены слов, по одному правилу `слово=замена` на строку         |

Значение `WORD_REPLACEMENTS` по умолчанию:

```text
дефис=-
двоеточие=:
точка с запятой=;
открывающая скобка=(
закрывающая скобка=)
```

Настройки интерфейса:

- **Тема** (тёмная/светлая) — для полного применения требуется перезапуск
- **Входное устройство** — выбор микрофона из списка; кнопка «Обновить» пересканирует устройства; сохраняется автоматически
- **Усиление микрофона** (1–50×) — применяется сразу и сохраняется; начните с 10–15×
- **Режим записи** — «Рация» или «Переключатель», применяется сразу и сохраняется
- **Горячие клавиши** — назначаются нажатием и сохраняются в `.env`; вступают в силу сразу
- **Путь к модели** — можно выбрать файл кнопкой «Обзор»; после смены требуется перезапуск
- **Стоп-слова** и **Замены слов** — редактируются в интерфейсе, применяются сразу и автоматически сохраняются в `.env`

## Зависимости

| Крейт            | Назначение                                              |
|------------------|---------------------------------------------------------|
| `eframe`/`egui`  | Графический интерфейс                                   |
| `whisper-rs`     | Локальное распознавание речи (`whisper.cpp`), функция `cuda` |
| `cpal`           | Захват аудио с микрофона                                |
| `tray-icon`      | Иконка и меню в системном трее                          |
| `chrono`         | Локальное время для группировки истории по датам        |
| `rfd`            | Диалог выбора файла модели                              |
| `reqwest`        | Загрузка файла модели с Hugging Face (блокирующий клиент) |
| `rdev`           | Симуляция нажатий `Ctrl+V` для вставки текста           |
| `arboard`        | Работа с буфером обмена                                 |
| `dotenvy`        | Загрузка `.env`                                         |
| `serde`/`serde_json` | Сериализация истории в `history.jsonl`              |
| `tokio`          | Асинхронный рантайм                                     |

Горячие клавиши отслеживаются через Win32 `GetAsyncKeyState` (опрос состояния клавиш), поэтому не зависят от фокуса активного окна. Полный список версий — в `Cargo.toml`.

## Вставка текста

После распознавания приложение кладёт текст в буфер обмена, имитирует `Ctrl+V` в активном окне и затем возвращает в буфер прежнее значение пользователя.

## Сборка релизной версии

```powershell
cargo build --release
```

Исполняемый файл появится в `target/release/whisper_flow_rust.exe`. Собирается без консольного окна (`#![cfg_attr(not(test), windows_subsystem = "windows")]`) и запускается как обычное GUI-приложение.

### Портативный релиз с библиотеками CUDA

Собранный exe жёстко зависит от библиотек CUDA (`cublas64_13.dll`, `cublasLt64_13.dll`) и Visual C++ runtime, поэтому на «чистой» Windows без них он не запустится. Чтобы пользователю не нужно было ничего устанавливать, скрипт `package.ps1` собирает самодостаточный архив — кладёт рядом с exe нужные DLL:

```powershell
pwsh .\package.ps1
```

Результат — папка `dist\VoiceAI` и архив `dist\VoiceAI-<версия>-win64.zip` (~420 МБ). Именно этот архив прикладывается к GitHub Release. Библиотеки берутся из установленного CUDA Toolkit (путь задаётся флагом `-CudaBin`), поэтому сборка самого exe всё равно требует CUDA на машине разработчика.

## Тесты

```powershell
cargo test
```

Покрыты модульными тестами: очистка текста от слов-паразитов, разбор стоп-слов, группировка истории по датам, разбор усиления микрофона и режима записи, эмодзи-иконки трея, а также экранирование значений `.env` (с проверкой round-trip через `dotenvy`). CI (`.github/workflows/ci.yml`) на `windows-latest` проверяет форматирование, `clippy`, сборку и тесты.

## Технические детали

- Аудио захватывается через `cpal` с выбранного устройства на нативной частоте и каналах, затем сводится в моно
- Сигнал ресемплируется линейно до 16 кГц, к нему применяется усиление, адаптивный шумовой порог и нормализация под уровень, удобный для Whisper
- Параметры распознавания: язык `ru`, без перевода, один сегмент, без таймстемпов, жадная стратегия (`Greedy`)
- Группировка истории по датам выполняется по локальному часовому поясу (`chrono`)
- Иконка трея создаётся в отдельном потоке с собственным циклом оконных сообщений (крейт `tray-icon` не потокобезопасен); цвет иконки меняется по флагу записи
- Мини-виджет и служебный «heartbeat» — самостоятельные viewport'ы `eframe`: они обновляются независимо от главного окна, что позволяет прятать главное окно в трей и возвращать его
- Для корректного отображения эмодзи подключается системный шрифт символов Windows; эмодзи рисуются монохромно
- Интерфейс построен на `egui`/`eframe`; запись, распознавание и сеть выполняются в отдельных потоках, не блокируя UI

## Fail-safe

- **Ошибка распознавания.** При сбое (модель не загружена, ошибка движка) приложение не падает: ошибка перехватывается, записывается в историю с пометкой `❌ Ошибка`, и работа продолжается.
- **Пустая реплика не вызывает вставку.** Если Whisper вернул пустой текст (тишина, нераспознанная речь) — вставка не происходит, буфер обмена не трогается.
- **Отсутствие модели не приводит к падению.** Если модель не найдена и скачать её не удалось, приложение всё равно запускается — сообщение об ошибке появится только при попытке распознавания.
- **Нет микрофона — нет падения.** Если устройство ввода недоступно (или выбранное устройство пропало), запись просто вернёт пустой буфер.
- **Буфер обмена восстанавливается.** После вставки приложение возвращает в буфер значение, которое было там до вставки.
- **Трей недоступен.** Если иконку в трее не удалось создать, закрытие главного окна завершает приложение (без «зависшего» окна).

## Известные ограничения

- Только Windows (используются Win32 `user32`/`GetAsyncKeyState`, `windows_subsystem`, симуляция ввода через `rdev`, трей)
- Язык распознавания жёстко задан как русский
- Для работы требуется NVIDIA GPU; для сборки из исходников — установленный CUDA Toolkit (в готовом релизе библиотеки упакованы)
- Эмодзи в интерфейсе монохромные (ограничение рендеринга `egui`)
- Смена пути к модели и темы применяется после перезапуска
- Первая загрузка модели (~1.6 ГБ) требует интернета и времени; идёт в фоне, до её завершения распознавание недоступно
- История ограничена 2000 записями
